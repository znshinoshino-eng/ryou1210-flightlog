# フライトログ

羽田空港の飛行機撮影スポット・カメラ設定・空港運用の仕組みなどを紹介するブログサイトです。

## 公開方法 (GitHub Pages)

1. このリポジトリのすべてのファイルを GitHub にアップロードする
2. リポジトリの Settings → Pages を開く
3. Source を「Deploy from a branch」、Branch を「main」/「(root)」に設定して Save
4. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## 記事を追加するとき

`articles/` フォルダに新しい `.html` ファイルを追加し、`index.html` の記事一覧にカードを1つ追加してください。
